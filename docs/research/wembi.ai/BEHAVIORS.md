# Wembi.ai — Behaviors

## Scroll
- Smooth scroll on `html:focus-within`
- Text lines use translateY reveal with stagger when `.is-inview`
- Steps sections swap media as labels change (scroll/click hybrid on original)
- Header logo is part of hero (not sticky site-wide)

## Click
- **FAQ:** radio-style tabs N°01–N°05 swap question + answer
- **Where:** accordion expands industry panels
- **How:** jumps/highlights Digital Twin vs Functioning step blocks
- **Contact pills:** mailto / tel

## Hover
- Links / pills have underline or gooey filter transitions
- Accent lime used for interactive bullets

## Responsive
- 6-col mobile → wider desktop grid (`--columns`)
- Hero text scales via `fs-130` fluid type (~97px @ 1440)
- Steps stack on mobile; side-by-side on desktop
